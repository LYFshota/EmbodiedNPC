# EmbodiedNPC

**Early Prototype** — an experimental Unity + Python project exploring NPC perception, cognition, memory, actions, and tasks in a café environment.

This public repository is being prepared for a future source release. It currently contains only this introduction; the Unity project and Python backend have not been published here, so it is not yet a clone-and-run demo.

The planned release is a complete Unity café demo with four NPCs and a player character. Third-party asset licensing and release validation must be completed before the source is uploaded. Original project code is intended to use Apache-2.0; third-party assets will retain their own licenses.

Questions, research discussion, and feedback are welcome through GitHub Issues.
