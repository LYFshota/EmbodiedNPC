# NativeWebSocket 来源与许可

项目使用 Endel Dreyer 的 `com.endel.nativewebsocket` **2.0.7**，固定 Git 提交为 `c612a4fef60f2ae57614b73202d2d261ba56aa3e`。

上游：[NativeWebSocket](https://github.com/endel/NativeWebSocket)。

该版本的 `package.json` 标注 MIT；官方仓库根目录提供 Apache-2.0 许可声明，项目保留了相应的 [许可证副本](NativeWebSocket_LICENSE.txt)（Git blob `9201a869da7fd8f91a65b31642c4ae9701f4e864`）。项目未对第三方包进行专门代码修改。

两项上游许可记录均予保留，具体使用以适用的许可证原文为准。
