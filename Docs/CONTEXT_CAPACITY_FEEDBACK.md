# 主模型默认容量与上下文提示

所有主模型的新配置默认 `32768` 上下文、`1024` 输出 Token。默认值是本地预算设置，不能证明某个模型实际支持 32K。已有明确保存的 8K、16K、自定义容量不迁移；旧的未声明容量继续沿用保守运行兜底。提供 8K/16K/32K/64K 选择和可编辑的自定义容量（1–1000000），Provider、模型独立配置保留。低于 16K 允许保存，并提醒必要输入可能超限，不强行升档。

目前模型发现返回名称，不自动验证最大窗口。未知能力的本地、自定义或其他 Provider 应按模型文档/部署值填写容量；默认 32K 不是自动探测结果。Ollama 的 `num_ctx` 使用该显式配置，云端也按该配置限制本地预算，不会把已选 8K/16K 改成 32K。若用户高估未知模型能力，仍可能被实际 Provider 拒绝；此时安全报错，不声称已经验证兼容。

现有 16K 用户：按 ESC → 设置 → AI 配置，选择原主模型配置，在高级设置中选择 32K，保存并应用；若显示待重启，按现有入口重启 Backend，再检查“实际运行配置容量”。只保存草稿不会改变正在运行的预算，也不会直接解除错误。若模型不支持目标容量，应选择其合法档位或更换模型。

## 受控诊断

新 Unity 请求以 `context_diagnostics_version=1` 选择接收外层 `context_status`。未声明的旧客户端不接收新增字段；仍保留未知字段拒绝、请求/Trace/Run/NPC 关联和过期 Run 拒绝。模型输出 Schema 没有增加诊断字段，模型不能决定容量提示。

预算器记录完整请求体的工程估算、必要输入成本，以及进入预算器的候选/完整保留/因 Token 上限丢弃的原子组数量。没有正文、身份持久键、认证值或完整 Prompt。每个 Run 最多两份检查，分别对应两个已有步骤。

- ERROR：必要输入不能满足有效预算，或适配器确认真实窗口/生成预留限制。Backend 通过正式关联的失败响应传递；不会调用模型绕过安全预算。
- WARNING：认知成功，但相关记忆、任务、近期发言至少一半的候选原子组因全局 Token 上限丢弃，或关键近期块/首项相关知识丢失。只部分保留近期块的 fallback 不视为完整保留。
- 普通检索数量限制、相关性筛选、固定近期窗口，以及只丢失较低优先级知识，不触发容量 WARNING。不读取全库来判断损失，也不增加模型推理。

## 持续错误与复核

Cafe 复用现有菜单组件及文字/按钮风格，在菜单、设置和对话之外显示单一非模态横幅。硬错误没有关闭按钮；切换 NPC、关闭对话、Backend 重连不会清空进程内错误。不同来源的成功不能解除旧错误。

每个必要输入故障携带已签名的成本诊断，不包含上下文正文。`POST /v1/context-budget/recheck` 只复核这些元数据和当前已生效的 Provider、模型、窗口及输出/思考预留，不调用模型、不读取玩家记忆、不触发任务或世界动作。相同适配器/模型的原必要输入满足新预算时才解除；不同配置族、实际 Provider 拒绝或验证失败，保留错误直到原来源对应步骤真实成功。配置增大但仍不够时继续显示。旧复核回执不能解除已经更新的故障。

签名密钥为数据目录中的 `context_capacity.key`，不含模型凭据，禁止提交。它只防止诊断元数据被篡改，不授予任何世界行动权限。Backend 重启后可以复核同一 Unity 进程保留的故障；不持久保存 Prompt 或失败请求。Unity 退出后的硬错误列表不落盘，新进程重新取得可信预算结果，避免陈旧错误永久存在。验证文件不可用时不自动解除，原来源成功仍可恢复。

## 一次性警告

警告为单张可关闭提示，硬错误优先显示。关闭后永久免打扰：便携游戏使用现有 `settings.json` 的可选布尔字段 `context_warning_dismissed`；Editor 沿用现有偏好模式使用 PlayerPrefs。语言、模型切换、重连、GameVisit 不重置该选择。偏好保存失败时不假称已经永久关闭。免打扰不抑制 ERROR 或 Backend 日志。

UI 中英文通过现有设置语言机制选择。真实导航标签为“设置 → AI 配置 → 高级设置”，不修改 NPC 本轮冻结回复语言或中英文长度合同。

## 不变与验收边界

Memory top-k/字符限额、近期对话窗口、Knowledge/Task 相关性筛选、认知两步上限、任务自主选择和动作权限不变。32K 不会自动填满；输出仍保留 1024，估算安全余量按现有公式增长至 3072，输入上限为 28672。16K 输入上限仍为 13824。

工程估算不是 Provider 实际 Token。真实 API usage、延迟、模型语义和 Standalone 不属于此次离线合同验证；保留此前 MODEL_SEMANTIC_WARN。
