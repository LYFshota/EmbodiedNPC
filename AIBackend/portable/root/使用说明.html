欢迎来到 EmbodiedNPC 咖啡馆

先连接一个聊天模型，再和四位 NPC 认识一下。本指南从解压开始，不需要编程，也不用输入命令。

快速开始配置 DeepSeek开始试玩常见问题项目与反馈

一、五步开始

  1. 01完整解压 ZIP
  2. 02双击「启动游戏.cmd」
  3. 03打开 AI 配置，填写模型
  4. 04保存，按提示立即重启
  5. 05进入咖啡馆，按 E 交谈

请先完整解压，别在压缩包里直接启动。启动游戏.cmd 就是入口；Start.cmd 也可以启动。

解压后看到这些很正常

Backend 和 UnityPlayer 是运行资源，Licenses 是许可证。保持它们和启动文件放在一起。首次启动会自动创建 UserData，用来保存设置、记忆和存档。

首次主菜单会提示需要完成 AI 配置。点击「配置 AI，进入咖啡馆」，或进入「设置 → AI 配置」。

二、配置模型：推荐 DeepSeek 官方 Flash

聊天模型负责 NPC 的思考和回复。这里用 DeepSeek 官方服务做示例；游戏安装包本身不包含这个云端聊天模型。

1. 准备自己的密钥

  1. 打开 DeepSeek 官方开放平台，按页面提示注册或登录。
  2. 进入 API keys 页面，创建一个新的 API Key；名称可以写「EmbodiedNPC 试玩」，方便自己辨认。
  3. 创建后复制平台显示的完整密钥并妥善保存。API Key 就是用于连接模型服务的个人密钥，不是登录密码，也不是模型名称。
  4. 在开放平台查看 API 账户余额。如果没有可用额度，在平台的充值页面按需充值；付款前以平台显示的金额和规则为准。网页版聊天能用，并不等于 API 账户一定有额度。

不需要购买或安装编程工具。本指南不会要求你提供或分享自己的密钥。

2. 在游戏里填写这四项

打开「设置 → AI 配置」。默认供应商是「自定义（OpenAI 兼容接口）」，本教程建议在下拉菜单里改选「DeepSeek」，直接使用游戏已有的官方适配。

游戏里的输入项填写什么
① 主模型供应商DeepSeek。选择后核对下面的地址和模型。
② 主模型 API 地址https://api.deepseek.com
这是游戏连接服务的地址，不是开放平台登录网址。无需自行添加 /responses 或 /chat/completions。
③ API 密钥粘贴你刚创建的完整 API Key。可以在输入框内右键 → 粘贴；显示为星号是正常的。不要填写截图里的演示内容。
④ 主模型deepseek-flash
这是模型 ID。按上述名称填写，或点击「获取模型」后选择该项。

「获取模型」会读取该服务提供的模型列表；列表读取失败时，也可以手动填入上面的模型 ID。「测试连接」会实际请求一次简短回复，游戏会先提示可能产生的 API 费用；确认后等待本次结果。

填写完成后先测试连接。显示通过，说明这份填写内容能完成简短回复；完整 NPC 对话还需要进游戏体验。若测试失败，按页面显示的具体原因处理，不必反复点测试。
不熟悉键盘复制粘贴？可以使用右键菜单

在输入框内点鼠标右键，选择「粘贴」。要替换已有内容，可以先选「全选」，再粘贴新内容。

3. 保存，再按提示重启

  1. 保留「记忆查找」里的「内置本地模型（推荐）」。Windows 试玩包已包含 EmbeddingGemma，正常试玩不用再填一套密钥或下载模型。
  2. 点击页面底部的「保存并应用配置」。如果按钮不在当前画面中，向下滚动到页面底部。
  3. 如果弹出「配置已保存」并提示需要重新启动游戏，点击「立即重启」。游戏会退出并重新打开，同时重启这份试玩包自己的 Backend 服务，不需要你另外操作命令行。
  4. 如果选择「稍后」，请正常退出游戏，等待启动窗口结束，再双击「启动游戏.cmd」。不要把“已保存待重启”当成“已经生效”。

上图右下角的⑥就是「保存并应用配置」。保存后请留意重启提示，不用另外找后台程序。

4. 确认可以开始

  • 重启后主菜单显示「AI 已就绪」。
  • AI 配置页不再提示待重启，运行中的模型是你选择的模型。
  • 点击「进入咖啡馆」，靠近 NPC 按 E 开始交谈。

修改地址、密钥或模型后，需要重新测试并保存。之前配置的测试成功，不代表新修改也已经验证。

我想使用其他云端服务或本地模型

可以选择已有的供应商预设，或保留「自定义（OpenAI 兼容接口）」，填写服务商提供的接口地址、密钥与模型 ID。不要把网页聊天地址填进接口栏，也不要把 DeepSeek 官方密钥用于第三方服务。特殊接口的高级参数按服务商说明填写；不是所有中转模型都兼容游戏的完整对话流程。本地服务需要先自行启动。

三、进咖啡馆，试着聊几句

按键作用
W / A / S / D移动角色。
鼠标调整视角。
Left Alt（左 Alt）切换释放 / 捕获鼠标。需要点击界面时释放鼠标，继续看向场景时再切回。
E靠近 NPC，出现互动提示后开始交谈。
Enter / 发送按钮在对话输入框写好消息后发送，等待 NPC 回复。
Esc关闭当前对话或返回；没有对话界面时打开菜单，可进入设置。
G打开玩家动作面板。

自由视角是可选设置：启用后用 Tab 切换；在自由视角中按 H 切换提示。第一次试玩先使用默认视角即可。

可以从这些话题开始
  • 和薇薇打招呼：「你好，第一次来，有什么推荐？」
  • 体验饮品请求：「薇薇，帮我做一杯拿铁吧。」观察她是否接受，以及实际服务结果。
  • 认识其他角色：「你平时为什么喜欢来这家咖啡馆？」
  • 体验记忆：「我比较喜欢不加糖的咖啡。」之后继续聊几句，再聊起自己的口味。记忆整理需要一些时间，不是说完每句话都会立刻形成长期记忆。

交谈时玩家会自然看向当前 NPC。结束对话后，头部会逐渐恢复正常姿态。打开设置还可以编辑 NPC 人设、玩家昵称与外观描述，或浏览世界知识。

正常退出：使用游戏里的「退出游戏」，等待启动窗口自动结束。下次从同一个解压目录启动，就会沿用该目录中的个人数据。更新版本前先正常退出并备份 UserData。

四、常见问题

双击后游戏没有打开

先确认已经完整解压，启动文件和 Backend、UnityPlayer 文件夹仍放在一起，并且目录可以写入。第一次启动需要等待资源加载。若提示同一份游戏已经运行，切回现有游戏窗口；不要连续双击多次。仍失败时，保留启动窗口的提示和 UserData/logs 中的日志用于反馈。

提示密钥无效或没有权限

核对供应商是否选为 DeepSeek、地址是否为本页示例，以及是否粘贴了完整的个人 API Key；前后不要多出空格。密钥被删除或撤销后，需要在官方平台重新创建，并在游戏里保存、按提示重启。

测试连接失败

检查网络、接口地址、模型 ID 和 API 账户额度。超时可以稍后再试；如果提示回复格式或思考控制不兼容，先使用本教程的 DeepSeek 官方预设。模型列表获取成功，只说明列表能读取，不代表对话一定可用。

消息发出去了，NPC 却没有回复

先等候当前请求完成，避免重复发送。查看游戏提示：超时通常与网络或模型速度有关；格式或字段错误说明模型回复未满足本次要求。确认运行中的配置已生效；使用第三方服务时可换回官方 DeepSeek 预设对照。需要进一步排查时，在开发者工具中运行「NPC 兼容性测试」，按弹窗确认费用。

API 额度不足怎么办？

回到 DeepSeek 开放平台查看 API 账户的余额和用量，按需充值后再试。聊天、连接测试和后台记忆处理都可能消耗 API 额度；游戏安装包不附赠云端服务额度。

明明保存了，为什么还在用旧模型？

“已保存”与“当前运行已应用”不同。按提示点击「立即重启」；如果选择过「稍后」，就正常退出，再从「启动游戏.cmd」启动。重新打开后核对运行状态，不要只看之前的测试结果。

本地模型回复很慢

本地速度取决于电脑性能、模型大小和正在运行的其他任务。可使用较小的模型或官方云端服务。先等一次请求结束，不要反复发送。内置的 EmbeddingGemma 负责记忆查找，不能代替聊天模型。
